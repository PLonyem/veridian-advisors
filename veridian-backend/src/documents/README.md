# Engagement Letter Template

`POST /api/leads/:id/engagement-letter-email` (in `leadRoutes.js`) reads a PDF
from this directory (`engagement-letter-template.pdf`) and passes it as a
buffer to `emailService.sendEngagementLetter()`, which attaches it to the
engagement letter email. That file is **not included in this repo** and is
not generated by any code here.

Before using `POST /api/leads/:id/engagement-letter-email`, place a real
engagement letter PDF at:

```
src/documents/engagement-letter-template.pdf
```

That document sets out scope of services, fees, and binding contract terms
for actual clients — it must be drafted or reviewed by qualified legal
counsel licensed in Veridian's operating jurisdiction before it's used. This
codebase intentionally does not fabricate that content.

Until the file is present, the endpoint returns a clear `500` error naming
this exact path instead of silently failing or sending a placeholder
document.
